# NSDC NMIMS Mumbai Chapter Website

A responsive single-page website for the National Student Data Corps (NSDC) Chapter at NMIMS Mumbai.

## Sections

- Chapter introduction
- About NSDC
- Activities & projects
- Faculty mentors
- 2026–27 core team
- Contact / connect
- Responsive mobile navigation
- Scroll-reveal interactions

## Content basis

Team names, roles, portfolios and official email addresses are based on the supplied **NSDC Core Team Directory | Academic Year 2026–27**.

The site keeps the supplied dates distinct: the broader NMIMS National Student Data Corps was founded in January 2023, while the NMIMS Mumbai chapter was founded in April 2026.

## Local development

No build step is required. Open `index.html` in a browser or run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Assets

The website expects the team photographs and hero imagery under `assets/` using the filenames referenced by `index.html`. The supplied DOCX contains the eight team/mentor photographs; those binary assets are also packaged separately with the working project files so they can be added to the repository when binary upload is available.
